# The name deck, read by scripts/names.mjs (npm run names).

# Two lists, each split into registers. A roll pairs one TWIST with one
# MEDIUM from different registers. A register marked "hot" never pairs with
# another hot register (material twist + weather medium is the slop axis).
# One entry per line; multi-word entries are fine. Lines starting with #
# are comments. Arcane word ids (fire, iron, seed, light...) are kept out on
# purpose so a rolled name never reads as a sentence.
#
# The quality lives here, not in the script. Cut freely.
