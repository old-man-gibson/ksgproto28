4. The verb: pick work, not a place

N7 stations row · N8 errands view

  • Stations: the places where you chose work and did not stop it by hand, newest first. "Back" returns to the last one.
  • Errands: every place grouped by what it is for, with the route time and the button that starts it.
  • Both route through the same rules as the map: no forced road, no gate, no unknown place.
